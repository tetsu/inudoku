# 🐕 Inudoku (イヌドク / 柴独)

> **「ワンコにもパーソナルスペースが必要です！」**  
> Zoodoku & Meowdoku にインスパイアされた、柴犬たちが主役のブラウザ向けロジックパズルゲーム。

---

## 📖 ゲーム概要

『**Inudoku**』は、世界中で大人気のロジックパズル（Queens / Star Battle パズル）をベースにしたパズルゲームです。  
プレイヤーは各エリア（テリトリー）に柴犬を1匹ずつ配置していきます。ただし柴犬たちはお互いの距離感を大切にするため、**隣り合わないように（斜めも含めて接触しないように）** 置く必要があります。

運や計算は一切不要！マインスイーパーや数独のような純粋な論理的思考でクリアを目指す、癒やしとやりごたえが詰まったゲームです。

---

## 🎯 ゲームルール

盤面は $N \times N$ のマス目で構成され、いくつかのカラーエリア（柴犬たちのドッグラン・お部屋）に色分けされています。

1. **エリアに1匹**: 各カラーエリアに柴犬（🐶）を **ちょうど1匹** 配置する
2. **行と列に1匹**: 各行（横一列）および各列（縦一列）に柴犬を **ちょうど1匹** 配置する
3. **触れ合いNG（パーソナルスペース）**: 柴犬同士は **縦・横・斜めの8方向すべてで隣接してはいけない**
4. **すべて配置できたらクリア**: すべての条件を満たして $N$ 匹の柴犬を無事に配置できればステージクリア！

---

## 🎮 遊び方・操作仕様

- **タップ / 左クリック**: 柴犬（🐶）を配置 / 解除
- **長押し / 右クリック / マーカー切替**: 「ここにはいない」目印（🐾 足跡 または ❌ バツマーク）を配置
- **ドラッグ操作**: マーカーの連続入力に対応（スマホでも快適）
- **オートマーク機能（アシスト）**: 柴犬を配置した際、自動で周囲8マスや同列・同行にマークをつける親切設定（ON/OFF切替可能）
- **ライフ制 / リラックスモード**:
  - **スタンダード**: 3回ミス（ルール違反の配置）したらゲームオーバー
  - **リラックス**: ミスペナルティなしでじっくり考えられる初心者向けモード

## 🐾 柴犬キャラクター & 演出

- **個性豊かな柴犬たち**:
  - 🐕 **赤柴**: 元気いっぱい、スタンダードな柴犬
  - 🐕‍🦺 **黒柴**: まろ眉がチャームポイント、クール系
  - 🤍 **白柴**: もちもちでマイペース
  - 🌾 **胡麻柴**: レアでちょっと大人っぽい
- **キュートなリアクション**:
  - 正しく配置したとき: 「ワン！」と元気よく吠えて尻尾を振る
  - 接触してしまったとき: 困り顔（汗マーク）で唸るアニメーション
  - クリア時: 柴犬たちが大喜びで飛び跳ねるお祝い演出

## 🛠 技術スタック・アーキテクチャ

ブラウザですぐに遊べる（インストール不要・高速起動）Webアプリケーションとして設計します。

| 項目 | 選定技術 | 選定理由 |
| :--- | :--- | :--- |
| **フロントエンド** | HTML5 / CSS3 / TypeScript (Vite) | 軽量・高速、フレームワーク非依存で軽快に動作 |
| **描画・UI** | Vanilla CSS + SVG / HTML Canvas | くっきり鮮明なベクター描画、滑らかなレスポンシブグリッド |
| **サウンド** | Web Audio API | 外部アセット遅延のないシンセ音 ＋ 柴犬の可愛いSE |
| **パズルエンジン** | バックトラッキング探索 & 自動生成 | ユニークな解（解が1通りだけ存在する）パズルを生成・検証 |
| **データ保存** | LocalStorage | クリア履歴、ベストタイム、カスタム設定の保存 |
| **配信** | GitHub Pages / 静的ホスティング | 完全クライアントサイド実行可能 |

## 📱 UI / UX デザイン方針

- **温もりある和風モダン × パステルデザイン**:
  - 柴犬の毛並みをイメージした温かみのあるベージュ、テラコッタ、くすみカラーのパレット。
- **モバイルファースト設計**:
  - スマートフォンの片手操作に最適化（親指が届きやすい下部にアクションバー配置）。
  - PCの大画面でも快適に遊べるレスポンシブレイアウト。
- **アクセシビリティ**:
  - 色覚多様性に配慮し、各カラーエリアには色の違いだけでなくパターンテクスチャ（ドットや斜線）の補助オプションを用意。

## 🚀 クイックスタート (ローカル起動)

### Antigravity版 (TypeScript + Vite)

```bash
cd antigravity

# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```

起動後、ブラウザで `http://localhost:5173/` にアクセスしてプレイできます。
