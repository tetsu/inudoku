# 🐕 Inudoku (イヌドク / 柴独)

> **「ワンコにもパーソナルスペースが必要です！」**  
> Zoodoku & Meowdoku にインスパイアされた、柴犬たちが主役のブラウザ向けロジックパズルゲーム。

---

## 📖 ゲーム概要

『**Inudoku**』は、世界中で大人気のロジックパズル（Queens / Star Battle パズル）をベースにしたパズルゲームです。  
プレイヤーは各エリア（テリトリー）に柴犬を1匹ずつ配置していきます。ただし柴犬たちはお互いの距離感を大切にするため、**隣り合わないように（斜めも含めて接触しないように）** 置く必要があります。

運や計算は一切不要！マインスイーパーや数独のような純粋な論理的思考でクリアを目指す、癒やしとやりごたえが詰まったゲームです。

---

## 🎯 ゲームルール

盤面は $N \times N$ のマス目で構成され、いくつかのカラーエリア（柴犬たちのドッグラン・テリトリー）に色分けされています。  
プレイヤーの目的は、**盤面に合計 $N$ 匹の柴犬（🐶）を、以下の3大ルールをすべて満たすように配置すること**です。

---

### 3大基本ルール

```
┌───────────────────────────────────────────────────────────┐
│  ① 各エリアに 1 匹   ：各カラー領域に柴犬はちょうど1匹     │
│  ② 各ラインに 1 匹   ：すべての行・すべての列に柴犬は1匹   │
│  ③ 触れ合い完全NG    ：柴犬同士は縦・横・斜めに隣接禁止！  │
└───────────────────────────────────────────────────────────┘
```

#### 1️⃣ エリア制約（テリトリーに1匹）
- 色分けされた各カラーエリア（ドッグラン）の中に、柴犬（🐶）を **ちょうど1匹だけ** 配置します。
- 0匹でも2匹以上でもいけません。

#### 2️⃣ ライン制約（行と列に1匹ずつ）
- すべての **横一列（行）** に柴犬は **ちょうど1匹**。
- すべての **縦一列（列）** に柴犬は **ちょうど1匹**。
- ※数独（Sudoku）と同様に、同じライン上で柴犬が重複することはありません。

#### 3️⃣ パーソナルスペース制約（8近傍接触禁止！）
- 柴犬たちは警戒心が強く、近すぎるとワンワン吠え合ってしまいます。
- そのため、柴犬同士は **上下左右だけでなく、斜めも含めた「周囲8マス」すべてで隣接してはいけません**。

```
  ┌───┬───┬───┐
  │ ❌│ ❌│ ❌│  ← 斜めも接触NG！
  ├───┼───┼───┤
  │ ❌│ 🐶│ ❌│  ← 柴犬を置くと、
  ├───┼───┼───┤
  │ ❌│ ❌│ ❌│  ← 周囲8マスはすべて立ち入り禁止
  └───┴───┴───┘
```

#### 🏆 クリア条件
- $N \times N$ の盤面に対して、ルール違反のない状態で **$N$ 匹すべての柴犬を配置完了** するとステージクリアです！

---

## 🛡️ システムによるルール徹底（安心設計）

プレイヤーが誤ってルール違反の柴犬を置いてしまわないよう、ゲームシステムが自動でルールを徹底・アシストします：

- **違反配置の自動防止（拒否システム）**:
  - すでに柴犬がいる同じ行・同じ列・同じ色のエリア、あるいは周囲8マスに2匹目の柴犬を置こうとすると、**配置がブロックされセルが左右に首を振ります（`denyShake`）**。
  - 「*同じ横列には1匹しか置けないワン！*」などの理由がトーストで即座に表示されます。
- **自動足跡マーク（Auto-Mark アシスト）**:
  - 柴犬を1匹置くと、その柴犬のパーソナルスペース（周囲8マス）と同列・同行・同エリアの空きマスに、**自動で「足跡（🐾）」がマーク**されます（ON/OFF切替可能）。

## 🎮 遊び方 & 操作方法

| 操作 | PC（マウス） | スマートフォン（タッチ） |
| :--- | :--- | :--- |
| **柴犬（🐶）の配置 / 解除** | 左クリック | 柴犬モードでタップ |
| **足跡（🐾）の配置 / 解除** | 右クリック / 足跡モードで左クリック | 足跡モードでタップ |
| **足跡の連続マーク** | ドラッグ | なぞるようにドラッグ |
| **配置のやり直し** | 元の柴犬をクリックして解除 | 元の柴犬をタップして解除 |

### 💡 攻略のヒント（消去法で解くコツ）
1. **狭いエリアに注目**: マス数が少ないカラーエリアは、柴犬の入る候補が最初から絞られています。
2. **足跡マーク（🐾）を活用**: 「ここには絶対に置けない」マスに足跡を打っていくと、ある行やエリアで**「ここしか置けるマスがない！」**という確定マスが見えてきます。
3. **ヒント機能（💡）**: どうしても詰まったときは、柴犬が論理的に確定するマスを教えてくれます。

  - クリア時: 柴犬たちが大喜びで飛び跳ねるお祝い演出

## 🛠 技術スタック・アーキテクチャ

ブラウザですぐに遊べる（インストール不要・高速起動）Webアプリケーションとして設計します。

| 項目 | 選定技術 | 選定理由 |
| :--- | :--- | :--- |
| **フロントエンド** | HTML5 / CSS3 / TypeScript (Vite) | 軽量・高速、フレームワーク非依存で軽快に動作 |
| **描画・UI** | Vanilla CSS + SVG / HTML Canvas | くっきり鮮明なベクター描画、滑らかなレスポンシブグリッド |
| **サウンド** | Web Audio API | 外部アセット遅延のないシンセ音 ＋ 柴犬の可愛いSE |
| **パズルエンジン** | バックトラッキング探索 & 自動生成 | ユニークな解（解が1通りだけ存在する）パズルを生成・検証 |
| **データ保存** | LocalStorage | クリア履歴、ベストタイム、カスタム設定の保存 |
| **配信** | GitHub Pages / 静的ホスティング | 完全クライアントサイド実行可能 |

## 📱 UI / UX デザイン方針

- **温もりある和風モダン × パステルデザイン**:
  - 柴犬の毛並みをイメージした温かみのあるベージュ、テラコッタ、くすみカラーのパレット。
- **モバイルファースト設計**:
  - スマートフォンの片手操作に最適化（親指が届きやすい下部にアクションバー配置）。
  - PCの大画面でも快適に遊べるレスポンシブレイアウト。
- **アクセシビリティ**:
  - 色覚多様性に配慮し、各カラーエリアには色の違いだけでなくパターンテクスチャ（ドットや斜線）の補助オプションを用意。
